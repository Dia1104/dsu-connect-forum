College Forum Web App

Description: Developed an intra-college collaboration platform where students can share ideas, ask questions, and discuss topics within the college community.

Technologies Used: Node.js, Express.js, MySQL, HTML, CSS, JavaScript

Features:

User registration and login with session management

Create, read, update, and delete posts (CRUD functionality)

Comment on posts and interact with peers

Responsive design for desktop and mobile

Learning Outcomes:

Built backend APIs using Node.js and Express

Connected and managed data with MySQL database

Learned about session handling, authentication, and dynamic web pages
